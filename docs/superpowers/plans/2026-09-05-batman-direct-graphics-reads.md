> **Superseded:** Do not execute this read-only plan. Use `2026-09-05-batman-direct-graphics-transactions.md`, implementing the approved direct Apply extension and immutable transaction-owned catalogs. Earlier ABI evidence remains useful; unchanged-write and shared mutable catalog requirements below are historical.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Execute inline unless Helena requests delegation; remain on main as requested.

**Goal:** Initialize all graphics values through synchronous native callbacks without read polling or read deadlines, preserving existing editing and Apply behavior.

**Architecture:** Capture one read-only INI snapshot per screen, publish the existing display catalogs, and transfer validated primitive values through the proven ExternalInterface interception. Keep transport ownership bounded and catalog ordering stable for the existing index-based Apply protocol. Verify numeric ABI and coordinator synchronization before expanding the installed hook.

**Tech Stack:** Windows x86 C++20, MSVC v143, ActionScript 2 generated by the C# SubtitleSizeModBuilder, PowerShell, Node.js, FFDec, native pack/delta verification.

**Spec:** `docs/superpowers/specs/2026-09-05-batman-direct-graphics-reads-design.md` (approved; commit `ded1fab`).

- `games/HelenBatmanAA/scripts/Test-BatmanDirectGraphicsFrontend.js`: generated/decompiled AS behavior tests using the experiment's existing extraction approach.

Wire contract, version 1 (all numbers must be finite integers):

```text
Helen_Graphics_BeginV1() -> generation | undefined
Helen_Graphics_GetV1(generation, field) -> integer | undefined
Helen_Graphics_ModeCountV1(generation, kind) -> integer | undefined
Helen_Graphics_ModeWidthV1(generation, kind, index) -> integer | undefined
Helen_Graphics_ModeHeightV1(generation, kind, index) -> integer | undefined
Helen_Graphics_EndV1(generation) -> true | undefined
kind: 0 Windowed, 1 Fullscreen
field: 0 Fullscreen, 1 Vsync, 2 Msaa, 3 Bloom, 4 DynamicShadows,
       5 MotionBlur, 6 Distortion, 7 FogVolumes, 8 SphericalHarmonicLighting,
       9 AmbientOcclusion, 10 Physx, 11 Stereo, 12 PersistedWidth,
       13 PersistedHeight, 14 DesktopWidth, 15 DesktopHeight
```

Detail remains derived, not a separately transported preset. Generations use positive uint32 values, never wrap/reuse within the process; exhaustion fails explicitly. A valid capture with invalid individual fields still receives a handle. Begin failure indicates transport/publication failure, not a fabricated collection of Off values.
